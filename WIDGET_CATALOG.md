# AORUI (An Other Rust UI) — Widget Catalog & Developer Guide

`AORUI` (*An Other Rust UI*) is a generalist, high-performance UI library designed for cyber-glass desktop applications and autonomous agent runtime environments. Built in Rust with WGPU 0.19, cosmic-text (via Glyphon), and Taffy flexbox layout.

---

## Architecture Overview

1. **Immediate-Mode Declaration, Retained Layout**: The UI hierarchy is built declaratively frame-by-frame via `WidgetTree`. Layout computation, hit-testing, and GPU SDF instancing are handled cleanly with zero memory leaks.
2. **GPU Dual-Kawase & SDF Rendering**: Every interactive card, button, tab, and menu is rendered as an analytic signed distance field (SDF) with rounded corners, specular reflections, neon borders, and dynamic multi-pass backdrop blur.
3. **Unified Event Dispatch**: `WidgetTree::dispatch_click` and `WidgetTree::dispatch_scroll` translate screen interactions directly into canonical `UiEvent`s, identical whether generated by a human pointer or an autonomous AI agent.
4. **Multi-Layer Rendering**: Background/Base UI and Overlays (Modals, Popovers, Dropdowns, Toasts, Tooltips) are rendered into segregated passes with automatic backdrop blur and crisp typography.

## Widget Catalog

### 1. Window & Dialog Containers

#### `WidgetTree::window`
Constructs a primary application window container with custom cyber-glass title bar, draggable header, and close button.
```rust
pub fn window(
    &mut self,
    id: impl Into<WidgetId>,
    title: impl Into<String>,
    children: &[NodeId],
    style: Style,
) -> Result<NodeId, LayoutError>
```
- **Events**: Emits `UiEvent::WindowCloseRequested { widget_id }` when the top-right close button is clicked.
- **Interactivity**: Header region is detected by `WidgetTree::is_window_title_bar(root, cursor_pos)` for native OS window dragging (`winit::window::Window::drag_window`).

#### `WidgetTree::modal_dialog`
Creates a modal overlay dialog with a 100% viewport backdrop, analytic background blur pass, and centered/draggable dialog card.
```rust
pub fn modal_dialog(
    &mut self,
    id: impl Into<WidgetId>,
    title: impl Into<String>,
    children: &[NodeId],
    dialog_style: Style,
) -> Result<NodeId, LayoutError>
```
- **Events**:
  - `UiEvent::ModalDismissed { modal_id }` when the backdrop or close button is clicked.
- **Interactivity**: Dialog header is detected by `WidgetTree::is_modal_title_bar(modal_root, cursor_pos)` for smooth dialog repositioning.

#### `WidgetTree::grid`
High-level CSS Grid container helper with $N$ equal-fraction columns and customizable column/row gaps.
```rust
pub fn grid(
    &mut self,
    columns: usize,
    column_gap: f32,
    row_gap: f32,
    children: &[NodeId],
    base_style: Style,
) -> Result<NodeId, LayoutError>
```
- **Layout Mechanics**: Uses Taffy `Display::Grid` with `grid_template_columns = vec![fr(1.0); columns]` for automated pixel-perfect column alignment.

#### `WidgetTree::custom_paint`
2D Custom drawing and graphics surface allowing developers to render custom graphics, shapes, lines, Bézier curves, polylines, and receive local/normalized interaction events.
```rust

    &mut self,
    id: impl Into<WidgetId>,
    commands: impl IntoIterator<Item = PaintCommand>,
    style: Style,
) -> Result<NodeId, LayoutError>
```
- **Painter Builder API**:
```rust

painter.line([0.0, 0.0], [100.0, 100.0], 2.0, [0.0, 1.0, 0.8, 1.0])
    .rect([10.0, 10.0, 80.0, 40.0], 4.0, Some([0.1, 0.2, 0.3, 0.8]), Some(([0.0, 0.85, 1.0, 1.0], 1.5)))
    .circle([50.0, 50.0], 20.0, Some([1.0, 0.0, 0.5, 0.8]), None)
    .bezier([0.0, 50.0], [40.0, 10.0], [60.0, 90.0], [100.0, 50.0], 3.0, [0.4, 0.8, 1.0, 1.0])
    .polyline(points, 2.0, [0.06, 0.72, 0.51, 1.0], false)
    .text([10.0, 80.0], "Signal Telemetry", 12.0, [0.9, 0.9, 0.9, 1.0]);
let canvas = tree.custom_paint("my_canvas", painter.finish(), leaf(400.0, 200.0)).unwrap();
```
- **Events**:
  - `UiEvent::CustomPaintPointerDown { widget_id, local_pos, normalized_pos }`
  - `UiEvent::CustomPaintPointerMove { widget_id, local_pos, delta }`

### Focus & Keyboard Navigation
`WidgetTree` provides built-in sequential focus cycling across all interactive inputs:
```rust
pub fn next_focusable(
    &self,
    root: NodeId,
    current_focused: Option<&str>,
    backward: bool,
) -> Result<Option<String>, LayoutError>
```
- Pressing **`Tab`** moves focus to the next focusable widget.
- Pressing **`Shift+Tab`** cycles focus backward in document layout order.
- Pressing **`Escape`** dismisses active overlays, menus, context popovers, or clears active focus.

## Quick Example

```rust
use ui_layout::{length, AlignItems, FlexDirection, Size, Style};
use ui_widgets::{IconKind, Theme, ToastKind, WidgetId, WidgetTree};

fn build_my_ui(tree: &mut WidgetTree) -> ui_layout::NodeId {
    let btn = tree.icon_button(WidgetId::new("scan_btn"), IconKind::Shield, true, leaf(36.0, 36.0)).unwrap();
    let toast = tree.toast(
        WidgetId::new("sys_toast"),
        "System Ready",
        "All clusters operational",
        ToastKind::Success,
        leaf(300.0, 60.0),
    ).unwrap();
    
    tree.container(&[btn, toast], column(12.0)).unwrap()
}
```
